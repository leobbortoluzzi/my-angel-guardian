# Project Overview

This is a single-page React application (SPA) built using Vite, TypeScript, and Tailwind CSS. The project appears to be generated by the Lovable AI platform (`lovable-tagger` is in the dependencies). It implements a specific landing page with components categorized under a "sacred" theme (e.g., `TopBanner`, `Hero`, `VideoBlock`, `AsSeenIn`, `FinalCTA`).

## Core Technologies
- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI primitives bundled via [shadcn/ui](https://ui.shadcn.com/)
- **Routing:** React Router v6 (`react-router-dom`)
- **State Management / Data Fetching:** TanStack React Query (`@tanstack/react-query`)
- **Testing:** Vitest and React Testing Library
- **Linting:** ESLint

## Directory Structure
- `src/`: Main source code directory.
  - `components/ui/`: Contains reusable, accessible UI components (shadcn/ui).
  - `components/sacred/`: Contains custom domain-specific components for the main landing page.
  - `pages/`: Contains the main route components (`Index.tsx`, `NotFound.tsx`).
  - `lib/`: Utility functions, notably `utils.ts` for Tailwind class merging (`cn`).
  - `hooks/`: Custom React hooks (e.g., `use-mobile.tsx`, `use-toast.ts`).
  - `test/`: Test setup and configuration files.

## Building and Running

The project utilizes `npm` (or `bun` as indicated by `bun.lockb`) for dependency management. The following commands are available:

- **Start Development Server:**
  ```bash
  npm run dev
  ```
  *(Starts the Vite dev server with hot module replacement)*

- **Build for Production:**
  ```bash
  npm run build
  ```
  *(Compiles the application into static files in the `dist` folder)*

- **Preview Production Build:**
  ```bash
  npm run preview
  ```

- **Run Tests:**
  ```bash
  npm run test
  ```
  *(Runs the Vitest test suite)*

- **Run Linter:**
  ```bash
  npm run lint
  ```

## Development Conventions

- **Component Architecture:** The application heavily relies on modular components. Shadcn UI is used for base elements, which are highly customizable via Tailwind.
- **Styling:** Tailwind CSS utility classes are the primary method for styling. The `cn` utility (using `clsx` and `tailwind-merge`) should be used when conditionally joining class names.
- **Routing:** Routes are configured centrally in `src/App.tsx` using `react-router-dom`.
- **Absolute Imports:** The `@/` alias is configured to point to the `src/` directory, simplifying import paths (e.g., `import { Button } from "@/components/ui/button"`).
- **Icons:** The `lucide-react` library is used for iconography.
